<p>AI와 머신러닝 모델은 결국 <strong>데이터를 기반으로 학습</strong>하기 때문에, 데이터를 올바르게 이해하고 해석하는 능력이 매우 중요하다. 따라서 통계는 데이터 분석뿐만 아니라 AI 모델을 이해하는 데도 필수적인 기초 지식이다.</p>

</ul>

<h1 id="1-데이터-분석data-analysis이란">1. 데이터 분석(Data Analysis)이란?</h1>
<p>데이터 분석이란</p>
<blockquote>
<p><strong>데이터에서 의미 있는 정보를 찾아 의사결정에 활용하는 과정</strong>이다.</p>
</blockquote>
<p>단순히 데이터를 보는 것이 아니라</p>
<ul>
<li>패턴 발견</li>
<li>문제 원인 분석</li>
<li>미래 예측</li>
<li>의사결정 지원</li>
</ul>
<p>등을 목적으로 한다.</p>
<hr />
<h2 id="데이터-분석-과정">데이터 분석 과정</h2>
<p>일반적인 데이터 분석 과정은 다음과 같다.</p>
<pre><code class="language-text">데이터 수집
      ↓
데이터 전처리
      ↓
데이터 탐색(EDA)
      ↓
분석 및 모델링
      ↓
결과 해석 및 시각화</code></pre>
<p>실제 프로젝트에서는 이 과정이 반복적으로 수행된다.</p>
<hr />

<p>데이터는 크게 <strong>정성적 데이터</strong>와 <strong>정량적 데이터</strong>로 구분된다.</p>

<h2 id="정성적-데이터">정성적 데이터</h2>
<h3 id="명목형nominal">명목형(Nominal)</h3>
<p>순서가 없는 데이터</p>
<p>예시</p>
<ul>
<li>성별</li>
<li>혈액형</li>
<li>직업</li>
</ul>
<hr />
<h3 id="순서형ordinal">순서형(Ordinal)</h3>
<p>순서는 있지만 간격은 일정하지 않은 데이터</p>
<p>예시</p>
<ul>
<li>만족도</li>
<li>학점</li>
<li>고객 등급</li>
</ul>
<hr />
<h2 id="정량적-데이터">정량적 데이터</h2>
<h3 id="이산형discrete">이산형(Discrete)</h3>
<p>정수 형태의 데이터 <strong>(셀 수 있다)</strong></p>
<p>예시</p>
<ul>
<li>학생 수</li>
<li>판매 개수</li>
</ul>
<hr />
<h3 id="연속형continuous">연속형(Continuous)</h3>
<p>실수 형태의 데이터 <strong>(셀 수 없다)</strong></p>
<p>예시</p>
<ul>
<li>키</li>
<li>몸무게</li>
<li>온도</li>
<li>시간</li>
</ul>

</ul>
</li>
<li><p><strong>연속형 변수(Continuous Variable)</strong> → <strong>&quot;얼마나 되는가?&quot;</strong>를 나타내는 측정 데이터</p>
<ul>
<li>예) 키, 몸무게, 온도, 시간</li>
</ul>
</li>
</ul>

<th>설명</th>

<ul>
<li><strong>독립변수</strong> : 공부 시간</li>
<li><strong>종속변수</strong> : 시험 점수</li>
<li><strong>통제변수</strong> : 시험 난이도, 공부 장소, 사용한 교재</li>
</ul>
<h3 id="예시-2-운동이-체중에-미치는-영향">예시 2. 운동이 체중에 미치는 영향</h3>
<ul>
<li><strong>독립변수</strong> : 운동 시간</li>
<li><strong>종속변수</strong> : 체중 변화</li>
<li><strong>통제변수</strong> : 식단, 수면 시간, 운동 종류</li>
</ul>
<blockquote>
<p><strong>쉽게 기억하기</strong></p>
<ul>
<li><strong>독립변수</strong> → 원인(Cause), 입력(Input)</li>
<li><strong>종속변수</strong> → 결과(Effect), 출력(Output)</li>
<li><strong>통제변수</strong> → 실험의 공정성을 위해 일정하게 유지하는 조건</li>
</ul>
</blockquote>

<p>대표적으로</p>
<ul>
<li>평균</li>
<li>중앙값</li>
<li>최빈값</li>
<li>분산</li>
<li>표준편차</li>
</ul>
<p>등이 있다.</p>

<h1 id="4-평균mean">4. 평균(Mean)</h1>
<p>평균은</p>
<blockquote>
<p>모든 값을 더한 후 데이터 개수로 나눈 값</p>
</blockquote>
<p>이다.</p>
<p>예시</p>
<pre><code class="language-text">10, 20, 30, 40</code></pre>
<p>평균</p>
<pre><code class="language-text">(10+20+30+40)/4 = 25</code></pre>
<hr />
<h2 id="평균의-특징">평균의 특징</h2>
<p>장점</p>
<ul>
<li>계산이 쉽다.</li>
<li>전체 데이터를 모두 반영한다.</li>
</ul>
<p>단점</p>
<ul>
<li>이상치(Outlier)의 영향을 많이 받는다.</li>
</ul>
<hr />
<h1 id="5-중앙값median">5. 중앙값(Median)</h1>
<p>중앙값은</p>
<blockquote>
<p>데이터를 크기순으로 정렬했을 때 가운데 위치한 값</p>
</blockquote>
<p>이다.</p>
<p>예시</p>
<pre><code class="language-text">3, 5, 7, 9, 100</code></pre>
<p>평균은 크게 증가하지만</p>
<p>중앙값은 <strong>7</strong>이다.</p>
<p>따라서 이상치가 존재할 때는 평균보다 중앙값이 대표값으로 적합한 경우가 많다.</p>
<hr />
<h1 id="6-최빈값mode">6. 최빈값(Mode)</h1>
<p>최빈값은</p>
<blockquote>
<p>가장 많이 등장하는 값</p>
</blockquote>
<p>이다.</p>
<p>예시</p>
<pre><code class="language-text">1,2,2,2,3,4</code></pre>
<p>최빈값</p>
<pre><code class="language-text">2</code></pre>
<p>범주형 데이터를 분석할 때 자주 사용된다.</p>
<hr />
<h3 id="퍼짐dispersion">퍼짐(Dispersion)</h3>
<blockquote>
<p><strong>퍼짐(산포)</strong>은 데이터가 <strong>중심값을 기준으로 얼마나 흩어져 있는지</strong>를 나타내는 통계량이다.</p>
</blockquote>
<ul>
<li>데이터가 중심값을 기준으로 얼마나 넓게 퍼져 있는지를 나타낸다.</li>
<li>평균이 같더라도 산포가 다르면 데이터의 특성과 변동성은 크게 달라질 수 있다.</li>
</ul>
<table>
<thead>
<tr>
<th>통계량</th>
<th>의미</th>
<th>특징</th>
<th>사용하면 좋은 경우 (When to Use)</th>
</tr>
</thead>
<tbody><tr>
<td><strong>분산 (Variance)</strong></td>
<td>평균으로부터 떨어진 정도를 제곱하여 평균낸 값</td>
<td>데이터의 변동성을 수치화하며, 값이 클수록 데이터가 더 넓게 퍼져 있음</td>
<td>통계 분석 및 머신러닝 알고리즘에서 데이터의 변동성을 분석할 때</td>
</tr>
<tr>
<td><strong>표준편차 (Standard Deviation)</strong></td>
<td>분산의 제곱근</td>
<td>가장 널리 사용되는 산포 지표이며, 원래 데이터와 같은 단위를 사용해 해석이 쉬움</td>
<td>데이터 간 변동성을 비교하거나 일반적인 산포를 확인할 때</td>
</tr>
<tr>
<td><strong>범위 (Range)</strong></td>
<td>최대값 − 최소값</td>
<td>계산이 매우 간단하지만 이상치(Outlier)의 영향을 크게 받음</td>
<td>전체 데이터의 분포 범위를 빠르게 파악할 때</td>
</tr>
<tr>
<td><strong>사분위수 범위 (IQR, Interquartile Range)</strong></td>
<td>Q3(75%) − Q1(25%)  (3사분위수 − 1사분위수)</td>
<td>가운데 50% 데이터의 범위를 나타내며 이상치의 영향을 적게 받음</td>
<td>이상치가 포함된 데이터를 분석하거나 이상치를 탐지할 때</td>
</tr>
<tr>

<td># 7. 분산(Variance)</td>
<td></td>
<td></td>
<td></td>
</tr>
</tbody></table>
<p>분산은</p>
<blockquote>
<p>데이터가 평균으로부터 얼마나 퍼져 있는지를 나타내는 값</p>
</blockquote>
<p>이다.</p>
<p>** 분산이 클수록**</p>
<ul>
<li>데이터가 넓게 퍼져 있고</li>
</ul>
<p><strong>분산이 작을수록</strong></p>
<ul>
<li>데이터가 평균 근처에 모여 있다.</li>
</ul>
<blockquote>
<p>즉, 평균이 같은 두 값도 <strong>산포도</strong>에 따라서 데이터를 다르게 해석 할 수 있다. 산포를 확인해야 데이터의 변동성과 안정성을 올바르게 이해할 수 있음</p>
</blockquote>
<hr />
<h1 id="8-표준편차standard-deviation">8. 표준편차(Standard Deviation)</h1>
<p>표준편차는</p>
<blockquote>
<p>분산의 제곱근으로, 데이터의 흩어진 정도를 원래 단위로 표현한 값</p>
</blockquote>
<p>이다.</p>
<p>예를 들어</p>
<ul>
<li>평균은 같더라도</li>

<h2 id="9사분위수-범위iqr-interquartile-range">9.사분위수 범위(IQR, Interquartile Range)</h2>
<p>사분위수 범위(IQR)는</p>
<blockquote>
<p><strong>데이터의 가운데 50%가 얼마나 퍼져 있는지를 나타내는 산포(퍼짐) 지표</strong>이다.</p>
</blockquote>
<p>최솟값과 최댓값 대신 <strong>중간에 위치한 데이터만을 사용</strong>하기 때문에 이상치(Outlier)의 영향을 거의 받지 않는다는 장점이 있다.</p>
<hr />
<h3 id="사분위수quartile란">사분위수(Quartile)란?</h3>
<p>데이터를 크기순으로 정렬한 뒤 <strong>4등분한 기준점</strong>을 의미한다.</p>
<ul>
<li><strong>Q1(제1사분위수)</strong> : 하위 25% 지점</li>
<li><strong>Q2(제2사분위수)</strong> : 중앙값(Median, 50%)</li>
<li><strong>Q3(제3사분위수)</strong> : 상위 75% 지점</li>
</ul>
<pre><code class="language-text">최솟값     Q1        Q2        Q3      최댓값
│────────│────────│────────│────────│
   25%       25%       25%       25%</code></pre>
<hr />
<h3 id="iqr-계산-공식">IQR 계산 공식</h3>
<p>$$
IQR = Q3 - Q1
$$</p>
<p>즉,</p>
<blockquote>
<p><strong>제3사분위수에서 제1사분위수를 뺀 값</strong>이다.</p>
</blockquote>
<hr />
<h3 id="예시">예시</h3>
<p>데이터</p>
<pre><code class="language-text">10, 12, 15, 18, 20, 25, 28, 30, 35</code></pre>
<h4 id="①-중앙값q2">① 중앙값(Q2)</h4>
<pre><code class="language-text">20</code></pre>
<h4 id="②-제1사분위수q1">② 제1사분위수(Q1)</h4>
<p>하위 데이터</p>
<pre><code class="language-text">10, 12, 15, 18</code></pre>
<p>Q1</p>
<pre><code class="language-text">(12 + 15) ÷ 2 = 13.5</code></pre>
<h4 id="③-제3사분위수q3">③ 제3사분위수(Q3)</h4>
<p>상위 데이터</p>
<pre><code class="language-text">25, 28, 30, 35</code></pre>
<p>Q3</p>
<pre><code class="language-text">(28 + 30) ÷ 2 = 29</code></pre>
<h4 id="④-iqr-계산">④ IQR 계산</h4>
<p>$$
IQR = Q3 - Q1
$$</p>
<p>$$
IQR = 29 - 13.5 = 15.5
$$</p>
<hr />
<h3 id="iqr을-사용하는-이유">IQR을 사용하는 이유</h3>
<p>평균이나 범위(Range)는 이상치의 영향을 크게 받는다.</p>
<p>예를 들어</p>
<pre><code class="language-text">20, 22, 23, 24, 25, 100</code></pre>
<p>여기서 <strong>100</strong>은 이상치이다.</p>
<ul>
<li><strong>범위(Range)</strong> = 100 − 20 = 80 (이상치의 영향이 큼)</li>
<li><strong>IQR</strong> = 가운데 50% 데이터만 사용하므로 큰 영향을 받지 않음</li>
</ul>
<p>따라서 <strong>집값, 연봉, 소득</strong>처럼 극단적인 값이 포함된 데이터를 분석할 때 IQR이 많이 사용된다.</p>
<hr />
<h3 id="언제-사용하는가">언제 사용하는가?</h3>
<ul>
<li>이상치가 포함된 데이터를 분석할 때</li>
<li>데이터의 실제 분포를 안정적으로 파악하고 싶을 때</li>
<li>박스플롯(Box Plot)에서 이상치를 판별할 때</li>
</ul>
<hr />
<h3 id="쉽게-기억하기-1">쉽게 기억하기</h3>
<table>
<thead>
<tr>
<th>범위(Range)</th>
<th>사분위수 범위(IQR)</th>
</tr>
</thead>
<tbody><tr>
<td>최대값 − 최소값</td>
<td>Q3 − Q1</td>
</tr>
<tr>
<td>전체 데이터 사용</td>
<td>가운데 50% 데이터 사용</td>
</tr>
<tr>
<td>이상치에 민감</td>
<td>이상치의 영향을 거의 받지 않음</td>
</tr>
</tbody></table>
<blockquote>
<p><strong>핵심 정리</strong></p>
<ul>
<li><strong>범위(Range)</strong>는 전체 데이터의 폭을 나타낸다.</li>
<li><strong>IQR(사분위수 범위)</strong>은 <strong>가운데 50% 데이터의 퍼짐 정도</strong>를 나타낸다.</li>
<li>이상치가 많은 데이터에서는 <strong>범위보다 IQR이 더 신뢰할 수 있는 산포 지표</strong>이다.</li>
</ul>
</blockquote>
<h1 id="10-이상치outlier">10. 이상치(Outlier)</h1>
<p>이상치는</p>
<blockquote>
<p>다른 데이터와 비교하여 매우 크거나 매우 작은 값</p>
</blockquote>
<p>을 의미한다.</p>
<p>예를 들어</p>
<pre><code class="language-text">20
22
21
23
150</code></pre>
<p>150은 이상치이다.</p>
<hr />
<h2 id="이상치의-영향">이상치의 영향</h2>
<p>이상치는</p>
<ul>
<li>평균을 크게 변화시키지만 중앙값은 거의 변하지 않는다</li>
<li>모델 성능을 저하시킬 수 있다.</li>
</ul>
<p>따라서 분석 전에 반드시 확인해야 한다. <strong>평균만 보고 데이터를 판단하면 오류가 발생할 수 있다.</strong></p>
<hr />
<h1 id="11-데이터-시각화의-중요성">11. 데이터 시각화의 중요성</h1>
<p>숫자만 보는 것보다</p>
<p>그래프로 표현하면</p>
<p>패턴과 이상치를 쉽게 발견할 수 있다.</p>
<p>대표적인 그래프</p>
<ul>
<li>막대그래프</li>
<li>히스토그램</li>
<li>박스플롯(Box Plot)</li>
<li>산점도(Scatter Plot)</li>
</ul>
<p>시각화는 데이터를 이해하는 첫 단계라고 할 수 있다.</p>
<hr />
<h1 id="12-edaexploratory-data-analysis">12. EDA(Exploratory Data Analysis)</h1>
<p>EDA는</p>
<blockquote>
<p><strong>탐색적 데이터 분석</strong>을 의미한다.</p>
</blockquote>
<p>모델을 만들기 전에 데이터를 먼저 이해하는 과정이다.</p>
<p>EDA에서는</p>
<ul>
<li>결측치 확인</li>
<li>이상치 확인</li>
<li>데이터 분포 확인</li>
<li>변수 간 관계 분석</li>
</ul>
<p>등을 수행한다.</p>
<p>좋은 모델을 만들기 위해서는 EDA가 반드시 선행되어야 한다.</p>
<hr />
<h1 id="13-데이터-분석에서-통계가-중요한-이유">13. 데이터 분석에서 통계가 중요한 이유</h1>
<p>AI 모델은 데이터를 학습하지만</p>
<p>데이터 자체를 이해하는 것은 사람의 역할이다.</p>
<p>따라서</p>
<ul>
<li>평균</li>
<li>분산</li>
<li>표준편차</li>
<li>데이터 분포</li>
</ul>
<p>등을 이해하지 못하면 모델의 결과를 올바르게 해석하기 어렵다.</p>
<p>즉,</p>
<blockquote>
<p><strong>통계는 AI와 데이터 분석의 언어(Language)</strong> 라고 할 수 있다.</p>
</blockquote>
<hr />
<h1 id="오늘의-핵심-정리">오늘의 핵심 정리</h1>
<ul>
<li>데이터 분석은 데이터를 활용해 의미 있는 정보를 도출하는 과정이다.</li>
<li>데이터는 정성적 데이터와 정량적 데이터로 구분된다.</li>
<li>기술통계는 데이터를 요약하고 특징을 파악하는 데 사용된다.</li>
<li>평균은 이상치의 영향을 많이 받으며, 중앙값은 이상치에 강하다.</li>
<li>분산과 표준편차는 데이터의 퍼진 정도를 나타내는 대표적인 지표이다.</li>
<li>이상치는 분석 결과에 큰 영향을 줄 수 있으므로 반드시 확인해야 한다.</li>
<li>EDA는 모델링 이전에 데이터를 이해하는 가장 중요한 단계이다.</li>
<li>통계는 데이터 분석뿐 아니라 AI 모델을 이해하는 데 필수적인 기초 지식이다.</li>
</ul>
<hr />
<h1 id="추가로-알아두면-좋은-개념">추가로 알아두면 좋은 개념</h1>
<h2 id="모집단population과-표본sample">모집단(Population)과 표본(Sample)</h2>
<p>모집단과 표본은 통계 분석에서 가장 기본이 되는 개념이다.</p>
<ul>
<li><strong>모집단(Population)</strong>: 분석하고자 하는 <strong>전체 대상</strong></li>
<li><strong>표본(Sample)</strong>: 모집단에서 <strong>일부를 추출한 데이터</strong></li>
</ul>
<p>실제 데이터 분석에서는 시간과 비용의 제약으로 인해 모집단 전체를 조사하기보다 <strong>표본을 추출하여 모집단의 특성을 추정</strong>하는 경우가 대부분이다.</p>
<hr />

<h3 id="예시-1-대한민국-성인의-평균-키">예시 1. 대한민국 성인의 평균 키</h3>
<ul>
<li><strong>모집단</strong>: 대한민국 성인 전체</li>
<li><strong>표본</strong>: 무작위로 선정한 성인 2,000명의 키 데이터</li>
</ul>
<p>→ 2,000명의 데이터를 분석하여 대한민국 성인의 평균 키를 추정한다.</p>
<hr />
<h3 id="예시-2-대학교-만족도-조사">예시 2. 대학교 만족도 조사</h3>
<ul>
<li><strong>모집단</strong>: 전체 학생</li>
<li><strong>표본</strong>: 재학생 500명을 무작위로 선정하여 설문조사</li>
</ul>
<p>→ 모든 학생을 조사하기 어렵기 때문에 일부 학생만 조사하여 전체 학생의 만족도를 추정한다.</p>
<hr />
<h3 id="왜-표본을-사용할까">왜 표본을 사용할까?</h3>
<ul>
<li>모든 데이터를 조사하기에는 시간과 비용이 많이 든다.</li>
<li>모집단이 너무 큰 경우 전체 조사가 현실적으로 어렵다.</li>
<li>적절한 표본만 추출해도 모집단의 특성을 높은 정확도로 추정할 수 있다.</li>
</ul>
<hr />
<h3 id="쉽게-기억하기-2">쉽게 기억하기</h3>
<blockquote>
<ul>
<li><strong>모집단(Population)</strong> = <strong>전체(Whole)</strong></li>
<li><strong>표본(Sample)</strong> = <strong>일부(Part)</strong></li>
</ul>
</blockquote>
<p>즉,</p>
<ul>
<li><strong>모집단</strong>은 &quot;전체를 알고 싶다.&quot;</li>
<li><strong>표본</strong>은 &quot;전체를 대표하는 일부를 조사한다.&quot;</li>
</ul>
<p>라는 개념으로 이해하면 쉽다.</p>
<blockquote>
<p><strong>핵심 정리</strong></p>
<ul>
<li><strong>모집단</strong>은 분석 대상 전체를 의미한다.</li>
<li><strong>표본</strong>은 모집단을 대표하도록 추출한 일부 데이터이다.</li>
<li>실제 데이터 분석에서는 대부분 <strong>표본을 이용하여 모집단의 특성을 추정</strong>한다.</li>
<li>표본이 모집단을 잘 대표할수록 분석 결과의 신뢰도가 높아진다.</li>
</ul>
</blockquote>
<hr />
<h2 id="상관관계correlation">상관관계(Correlation)</h2>
<p>상관관계는 <strong>두 변수 간의 관계 정도</strong>를 나타낸다.</p>
<p>예를 들어</p>
<ul>
<li>공부 시간 ↑ → 시험 점수 ↑ : 양의 상관관계</li>
<li>운동량 ↑ → 체지방률 ↓ : 음의 상관관계</li>
</ul>
<p>하지만 <strong>상관관계가 반드시 인과관계를 의미하지는 않는다.</strong></p>
<hr />
<h2 id="정규분포normal-distribution">정규분포(Normal Distribution)</h2>
<p>정규분포는 자연현상에서 가장 많이 나타나는 데이터 분포이다.</p>
<p>대표적인 특징은</p>
<ul>
<li>평균을 중심으로 좌우 대칭</li>
<li>평균, 중앙값, 최빈값이 모두 같다.</li>
<li>데이터의 대부분이 평균 근처에 위치한다.</li>
</ul>
<p>많은 통계 기법과 머신러닝 알고리즘은 데이터가 정규분포를 따른다고 가정한다.</p>
<hr />
<h2 id="결측치missing-value">결측치(Missing Value)</h2>
<p>결측치는 데이터가 비어 있는 값을 의미한다.</p>
<p>예를 들어</p>
<table>
<thead>
<tr>
<th>이름</th>
<th>나이</th>
</tr>
</thead>
<tbody><tr>
<td>홍길동</td>
<td>25</td>
</tr>
<tr>
<td>김철수</td>
<td>NULL</td>
</tr>
</tbody></table>
<p>결측치를 그대로 사용하면 분석 결과가 왜곡될 수 있으므로 삭제하거나 평균값 등으로 대체하는 전처리가 필요하다.</p>

<h1 id="느낀-점">느낀 점</h1>
<p>이번 학습을 통해 데이터 분석은 단순히 숫자를 계산하는 것이 아니라 <strong>데이터를 이해하고 의미를 찾는 과정</strong>이라는 점을 알게 되었다.</p>
<p>특히 평균과 표준편차 같은 기초 통계 개념은 이후 머신러닝과 AI를 학습할 때 계속 활용되는 핵심 개념이라는 것을 이해했다. 앞으로는 모델을 만들기 전에 데이터를 먼저 탐색하고 이해하는 습관을 기르는 것이 중요하다고 느꼈다.</p>
