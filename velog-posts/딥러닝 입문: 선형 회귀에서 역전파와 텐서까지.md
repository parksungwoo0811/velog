<h1 id="들어가기-바나나로-이해하는-규칙-기반-ml-dl">들어가기: 바나나로 이해하는 규칙 기반, ML, DL</h1>
<h2 id="1-사람이-규칙을-만드는-방식">1. 사람이 규칙을 만드는 방식</h2>

길고 + 하얗고 + 납작하면 → 바나나 조각</code></pre>
<p>이 방식에서는 사람이 중요한 특징을 먼저 정합니다. 규칙 기반 시스템이나 전통적 분석의 일부 접근을 떠올릴 수 있습니다.</p>
<h2 id="2-머신러닝-방식">2. 머신러닝 방식</h2>
<p>머신러닝에서는 바나나 이미지와 정답을 많이 제공하고, 어떤 특징 조합이 바나나를 잘 구별하는지 모델이 학습합니다. 전통적인 ML에서는 색, 길이, 곡률 같은 특징을 사람이 먼저 계산해 제공하는 경우가 많습니다.</p>
<pre><code class="language-text">사람이 만든 특징
→ 머신러닝 모델
→ 바나나 여부</code></pre>
<h2 id="3-딥러닝-방식">3. 딥러닝 방식</h2>
<p>딥러닝은 원본 이미지에 가까운 데이터를 받고, 여러 층을 거치며 구분에 필요한 특징 표현까지 함께 학습합니다.</p>
<pre><code class="language-text">픽셀
→ 낮은 층: 선과 모서리
→ 중간 층: 곡선과 질감
→ 높은 층: 과일의 전체 형태
→ 바나나 여부</code></pre>
<p>핵심은 특징 추출이 사라진다는 뜻이 아니라 <strong>특징을 사람이 일일이 설계하는 비중이 줄고, 모델이 목적에 맞는 표현을 학습한다</strong>는 뜻입니다.</p>

<h1 id="part-1-회귀분석-재해석">Part 1. 회귀분석 재해석</h1>
<h2 id="1-선형-회귀부터-시작하는-이유">1. 선형 회귀부터 시작하는 이유</h2>
<p>딥러닝의 뉴런 하나가 하는 기본 계산은 선형 회귀와 닮았습니다.</p>
<p>$$
\hat{y} = wx + b
$$</p>
<ul>
<li>$x$: 입력값 또는 Feature</li>
<li>$w$: 가중치</li>
<li>$b$: 편향 또는 절편</li>
<li>$\hat{y}$: 예측값</li>
<li>$y$: 실제 정답 또는 Target</li>
</ul>
<p>입력이 여러 개면 다음처럼 확장됩니다.</p>
<p>$$
\hat{y} = \sum_{i=1}^{n} x_i w_i + b
$$</p>
<p>딥러닝은 이런 계산을 수행하는 노드를 여러 층으로 연결하고, 활성화 함수를 넣어 복잡한 관계를 학습합니다.</p>
<h2 id="2-키-예측-예시">2. 키 예측 예시</h2>
<p>몸무게로 키를 예측한다고 가정해 봅시다.</p>
<table>
<thead>
<tr>
<th align="right">몸무게 $x$</th>
<th align="right">실제 키 $y$</th>
</tr>
</thead>
<tbody><tr>
<td align="right">58</td>
<td align="right">174</td>
</tr>
<tr>
<td align="right">59</td>
<td align="right">175</td>
</tr>
<tr>
<td align="right">60</td>
<td align="right">176</td>
</tr>

<p>처음에는 $w$와 $b$를 모르므로 임의의 값에서 시작할 수 있습니다.</p>
<p>$$
\hat{y}=1.2x+100
$$</p>
<p>몸무게가 58이라면 예측 키는 169.6입니다.</p>
<p>$$
\hat{y}=1.2 \times 58 + 100 = 169.6
$$</p>
<p>실제 키가 174라면 차이는 4.4입니다. 학습은 이 차이가 작아지도록 $w$와 $b$를 반복해서 바꾸는 과정입니다.</p>
<h2 id="3-parameter와-hyperparameter">3. Parameter와 Hyperparameter</h2>
<h3 id="학습으로-찾는-parameter">학습으로 찾는 Parameter</h3>
<ul>
<li>가중치 $w$</li>
<li>편향 $b$</li>
</ul>
<h3 id="사람이-설정하거나-탐색하는-hyperparameter">사람이 설정하거나 탐색하는 Hyperparameter</h3>
<ul>
<li>Learning Rate</li>
<li>Batch Size</li>
<li>Epoch 수</li>
<li>층의 수와 뉴런 수</li>
<li>Dropout 비율</li>
</ul>
<p>Parameter는 데이터로부터 학습되고, Hyperparameter는 학습 방법과 모델 구조를 조절합니다.</p>
<h2 id="4-파라미터를-구하는-다섯-단계">4. 파라미터를 구하는 다섯 단계</h2>
<h3 id="step-1-데이터-정의">Step 1. 데이터 정의</h3>
<p>Feature $x$와 Target $y$를 준비합니다. 타입, 결측치, 단위, Train·Validation·Test 분할도 확인합니다.</p>
<h3 id="step-2-모델-또는-가설-정의">Step 2. 모델 또는 가설 정의</h3>
<p>가장 단순한 선형 모델은 다음과 같습니다.</p>
<p>$$
\hat{y}=wx+b
$$</p>
<p>신경망에서는 입력층, 은닉층, 출력층의 구조와 활성화 함수를 정합니다.</p>
<h3 id="step-3-손실-함수-정의">Step 3. 손실 함수 정의</h3>
<p>예측이 얼마나 틀렸는지 숫자로 측정합니다. 회귀의 대표 손실은 MSE입니다.</p>
<p>$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$</p>
<p>오차를 제곱하므로 양수와 음수가 상쇄되지 않고 큰 오차에 더 큰 벌점을 줍니다.</p>
<h3 id="step-4-손실-최소화">Step 4. 손실 최소화</h3>
<p>단순 선형 회귀는 최소제곱법으로 해를 직접 구할 수 있습니다. 딥러닝은 파라미터가 많고 비선형 구조이므로 Gradient Descent 계열의 반복 최적화를 주로 사용합니다.</p>
<h3 id="step-5-파라미터-업데이트">Step 5. 파라미터 업데이트</h3>
<p>손실이 줄어드는 방향으로 $w$와 $b$를 수정합니다. 이 과정을 여러 Batch와 Epoch 동안 반복합니다.</p>
<h2 id="5-선형-회귀와-딥러닝의-공통-구조">5. 선형 회귀와 딥러닝의 공통 구조</h2>

<h2 id="6-활성화-함수가-필요한-이유">6. 활성화 함수가 필요한 이유</h2>
<p>선형 함수를 여러 번 연결해도 결국 하나의 선형 함수로 합쳐집니다.</p>
<p>$$
f_2(f_1(x)) = W_2(W_1x+b_1)+b_2 = W'x+b'
$$</p>
<p>층을 많이 쌓아도 활성화 함수가 없다면 복잡한 비선형 경계를 만들 수 없습니다. 그래서 각 층의 선형 계산 뒤에 활성화 함수를 넣습니다.</p>
<pre><code class="language-text">입력 → 가중합 → 활성화 함수 → 다음 층</code></pre>
<h2 id="7-주요-활성화-함수">7. 주요 활성화 함수</h2>
<h3 id="71-sigmoid">7.1 Sigmoid</h3>
<p>$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$</p>
<ul>
<li>출력 범위: 0과 1 사이</li>
<li>장점: 이진 분류의 출력 확률 표현에 적합</li>
<li>단점: 극단 영역에서 기울기가 거의 0이 되어 기울기 소실 가능</li>
<li>활용: 이진 분류 출력층</li>
</ul>
<h3 id="72-tanh">7.2 Tanh</h3>
<p>$$
\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}
$$</p>
<ul>
<li>출력 범위: -1과 1 사이</li>
<li>장점: 출력이 0을 중심으로 분포</li>
<li>단점: 극단 영역에서 기울기 소실 가능</li>
<li>활용: 전통적인 RNN 내부 상태 등</li>
</ul>
<h3 id="73-relu">7.3 ReLU</h3>
<p>$$
ReLU(x)=\max(0,x)
$$</p>
<ul>
<li>음수 입력(0보다 작으면): 0</li>
<li>양수 입력(0보다 크면): 그대로 전달</li>
<li>장점: 계산이 단순하고 양수 구간의 기울기가 일정</li>
<li>단점: 계속 음수만 입력되는 뉴런은 죽을 수 있음</li>
<li>활용: 대부분의 일반적인 은닉층</li>
</ul>
<p>ReLU는 음수 신호를 막고 양수 신호만 통과시키는 문과 비슷합니다. 각 뉴런이 특정 조건에서 반응하게 하여 신경망이 여러 조각 함수를 조합할 수 있게 합니다.</p>
<blockquote>
<p>ReLU가 음수를 0으로 만든다고 해서 음수 값이 언제나 불필요하다는 뜻은 아닙니다. 해당 뉴런이 학습한 좌표계에서 활성 조건을 통과하지 못한 신호를 0으로 만든다고 이해해야 합니다.</p>
</blockquote>
<h2 id="part-1-핵심-정리">Part 1 핵심 정리</h2>
<ul>
<li>딥러닝 뉴런의 기본 계산은 $wx+b$와 닮았습니다.</li>
<li>데이터로 학습하는 값은 Parameter, 사람이 설정·탐색하는 값은 Hyperparameter입니다.</li>
<li>손실 함수는 실제값과 예측값의 차이를 수치화합니다.</li>
<li>활성화 함수가 없으면 여러 선형층도 하나의 선형 함수와 같습니다.</li>
<li>Sigmoid는 이진 출력, Tanh는 -1~1 상태 표현, ReLU는 일반 은닉층에 주로 사용됩니다.</li>
</ul>

<h1 id="part-2-모델-최적화">Part 2. 모델 최적화</h1>
<h2 id="1-최적화란">1. 최적화란?</h2>
<p>최적화는 제한된 조건 안에서 비용을 최소화하거나 효율을 최대화하는 과정입니다.</p>
<ul>
<li>물류: 가장 짧은 배송 경로</li>
<li>공학: 무게는 줄이고 강도는 높이는 설계</li>
<li>경제: 한정된 예산의 효율적인 배분</li>
<li>딥러닝: 예측 손실을 작게 만드는 파라미터 찾기</li>
</ul>
<p>딥러닝의 수학적 목표는 보통 다음과 같습니다.</p>
<p>$$
\theta^*=\arg\min_{\theta} L(\theta)
$$</p>
<p>$\theta$는 모든 가중치와 편향, $L$은 손실 함수입니다.</p>
<h2 id="2-목적별-손실-함수">2. 목적별 손실 함수</h2>
<h3 id="회귀">회귀</h3>
<ul>
<li>MSE: 큰 오차에 더 큰 벌점</li>
<li>RMSE: MSE에 제곱근을 씌워 Target과 같은 단위로 해석</li>
<li>MAE: 절댓값 오차라 이상치에 MSE보다 덜 민감</li>
</ul>
<h3 id="분류">분류</h3>
<ul>
<li>Binary Cross Entropy: 이진 분류</li>
<li>Categorical Cross Entropy: 다중 클래스 분류</li>
</ul>
<p>이진 분류의 Cross Entropy는 다음과 같습니다.</p>
<p>$$
L=-[y\log(p)+(1-y)\log(1-p)]
$$</p>
<p>정답이 1인데 모델이 0.01처럼 자신 있게 틀리면 큰 손실을 줍니다.</p>
<blockquote>
<p>단순한 $y-\hat{y}$는 오차이지만 그 자체가 항상 좋은 손실 함수는 아닙니다. 학습 목적에 맞고 미분 가능한 손실을 선택해야 합니다.</p>
</blockquote>
<h2 id="3-한-epoch의-학습-과정">3. 한 Epoch의 학습 과정</h2>
<ol>
<li>입력 Batch를 신경망에 넣습니다.</li>
<li>Forward Propagation으로 예측합니다.</li>
<li>실제값과 예측값으로 손실을 계산합니다.</li>
<li>Backpropagation으로 각 파라미터의 기울기를 계산합니다.</li>
<li>SGD나 Adam 같은 Optimizer가 파라미터를 업데이트합니다.</li>
<li>다음 Batch로 이동합니다.</li>
</ol>
<p>모든 학습 데이터를 한 번 사용하면 1 Epoch입니다.</p>
<h2 id="4-gradient-descent">4. Gradient Descent</h2>
<p>경사하강법은 현재 위치의 기울기를 보고 손실이 감소하는 방향으로 파라미터를 움직입니다.</p>
<p>$$
w_{t+1}=w_t-\eta\frac{\partial L}{\partial w_t}
$$</p>
<ul>
<li>$w_t$: 현재 가중치</li>
<li>$\eta$: Learning Rate</li>
<li>$\frac{\partial L}{\partial w_t}$: 손실 기울기</li>
<li>$w_{t+1}$: 새 가중치</li>
</ul>
<h3 id="산-내려가기-비유">산 내려가기 비유</h3>
<ul>
<li>손실 함수: 산의 지형</li>
<li>현재 가중치: 등산객의 현재 위치</li>
<li>기울기: 가장 가파른 방향</li>
<li>Learning Rate: 한 걸음의 크기</li>
<li>손실 최소점: 도착하려는 계곡</li>
</ul>
<p>손실을 줄이기 위해 기울기의 반대 방향으로 이동하므로 업데이트 식에 마이너스가 있습니다.</p>
<h2 id="5-learning-rate">5. Learning Rate</h2>
<p>학습률은 한 번 업데이트할 때 얼마나 크게 움직일지를 정합니다.</p>
<h3 id="너무-작으면">너무 작으면</h3>
<ul>
<li>최솟값을 향해 천천히 이동</li>
<li>학습 시간이 길어짐</li>
<li>평평한 구간에서 거의 움직이지 못할 수 있음</li>
</ul>
<h3 id="너무-크면">너무 크면</h3>
<ul>
<li>최솟값을 지나치는 Overshooting</li>
<li>손실이 진동하거나 발산</li>
<li>좋은 영역에서 벗어남</li>
</ul>
<p>학습 초기에 크게 움직이고 후반에 작게 줄이는 Scheduler를 사용할 수도 있습니다.</p>
<blockquote>
<p>학습률은 반드시 0과 1 사이여야 하는 값이 아니며, 항상 $10^{-5}$에서 시작해야 하는 것도 아닙니다. Adam에서는 $10^{-3}$이 흔한 출발점이고 모델과 Optimizer에 따라 달라집니다.</p>
</blockquote>
<h2 id="6-손실-지형의-여러-지점">6. 손실 지형의 여러 지점</h2>
<ul>
<li><strong>Global Minimum</strong>: 전체 지형에서 가장 낮은 지점</li>
<li><strong>Local Minimum</strong>: 주변에서는 가장 낮지만 전체 최저는 아닌 지점</li>
<li><strong>Saddle Point</strong>: 방향에 따라 오르막과 내리막이 함께 있는 지점</li>
<li><strong>Plateau</strong>: 기울기가 매우 작은 평평한 구간</li>
</ul>
<p>경사하강법은 현재 위치의 국소 기울기만 사용하므로 시작 위치와 지형에 영향을 받습니다. Optimizer는 학습을 돕지만 항상 Global Minimum 도달을 보장하지는 않습니다.</p>
<h2 id="7-forward-propagation">7. Forward Propagation</h2>
<p>순전파는 입력에서 출력 방향으로 계산합니다.</p>
<p>$$
h_1=f(x_1w_1+x_2w_3+b_1)
$$</p>
<p>$$
h_2=f(x_1w_2+x_2w_4+b_2)
$$</p>
<p>$$
\hat{y}=g(h_1w_5+h_2w_6+b_3)
$$</p>
<p>마지막으로 $\hat{y}$와 $y$를 비교해 손실을 계산합니다.</p>
<pre><code class="language-text">입력 → 은닉층 → 출력 → 손실</code></pre>
<h2 id="8-backpropagation">8. Backpropagation</h2>
<p>역전파는 손실이 각 파라미터에 얼마나 민감한지 Chain Rule로 효율적으로 계산합니다.</p>
<p>$$
\frac{\partial E}{\partial w_6}
=
\frac{\partial E}{\partial \hat{y}}
\frac{\partial \hat{y}}{\partial w_6}
$$</p>
<p>제곱 오차를 다음처럼 정의해 봅시다.</p>
<p>$$
E=\frac{1}{2}(\hat{y}-y)^2
$$</p>
<p>그러면</p>
<p>$$
\frac{\partial E}{\partial \hat{y}}=\hat{y}-y
$$</p>
<p>출력 계산이 $\hat{y}=h_1w_5+h_2w_6$이라면</p>
<p>$$
\frac{\partial \hat{y}}{\partial w_6}=h_2
$$</p>
<p>따라서</p>
<p>$$
\frac{\partial E}{\partial w_6}=(\hat{y}-y)h_2
$$</p>
<p>가 됩니다.</p>
<p>팀 프로젝트 결과가 나빴을 때 앞 단계의 각 결정이 최종 결과에 얼마나 영향을 줬는지 거꾸로 추적하고, 영향이 큰 부분을 더 많이 수정하는 것과 비슷합니다.</p>
<ul>
<li><strong>Backpropagation</strong>: 각 파라미터의 기울기를 계산</li>
<li><strong>Optimizer</strong>: 계산된 기울기로 파라미터를 업데이트</li>
</ul>
<p>역전파와 경사하강법은 연결되어 있지만 같은 개념은 아닙니다.</p>
<h2 id="9-optimizer의-종류">9. Optimizer의 종류</h2>
<h3 id="91-batch-gradient-descent">9.1 Batch Gradient Descent</h3>
<p>전체 학습 데이터로 한 번의 기울기를 계산합니다. 안정적이지만 대규모 데이터에서는 계산과 메모리 부담이 큽니다.</p>
<h3 id="92-sgd">9.2 SGD</h3>
<p>엄밀한 SGD는 샘플 하나씩 업데이트합니다. 실무에서는 Mini-batch SGD를 흔히 SGD라고 부릅니다.</p>
<ul>
<li>빠르고 계산이 가벼움</li>
<li>노이즈가 정체 구간을 벗어나는 데 도움을 줄 수 있음</li>
<li>경로가 흔들리고 수렴이 불안정할 수 있음</li>
</ul>
<h3 id="93-momentum">9.3 Momentum</h3>
<p>이전 기울기 방향을 누적해 관성을 만듭니다.</p>
<pre><code class="language-text">현재 경사 + 지금까지 진행하던 방향
→ 지그재그 감소, 빠른 이동</code></pre>
<h3 id="94-adagrad">9.4 AdaGrad</h3>
<p>파라미터마다 과거 기울기 제곱을 누적해 학습률을 조절합니다. 드문 특성에 유용할 수 있지만 학습률이 지나치게 작아질 수 있습니다.</p>
<h3 id="95-rmsprop">9.5 RMSProp</h3>
<p>기울기 제곱의 지수 이동 평균을 사용해 AdaGrad의 학습률 감소 문제를 완화합니다.</p>
<h3 id="96-adam">9.6 Adam</h3>
<p>Adam은 다음 두 정보를 함께 사용합니다.</p>
<ol>
<li>기울기의 지수 이동 평균: 진행 방향 기억</li>
<li>기울기 제곱의 지수 이동 평균: 변동 크기에 맞춰 보폭 조정</li>
</ol>
<pre><code class="language-text">Momentum의 방향 기억
+ RMSProp 계열의 적응형 보폭
→ Adam</code></pre>
<p>Adam은 기본 선택으로 많이 사용되지만 모든 문제에서 SGD보다 좋은 것은 아닙니다. 수렴 속도와 최종 일반화 성능을 함께 비교해야 합니다.</p>
<h2 id="10-gradient-vanishing과-exploding">10. Gradient Vanishing과 Exploding</h2>
<h3 id="101-gradient-vanishing">10.1 Gradient Vanishing</h3>
<p>1보다 작은 값이 여러 층에서 계속 곱해지면 기울기가 0에 가까워집니다.</p>
<pre><code class="language-text">0.5 × 0.5 × 0.5 × 0.5 × ...
→ 거의 0</code></pre>
<p>결과:</p>
<ul>
<li>입력에 가까운 층이 거의 학습되지 않음</li>
<li>가중치 업데이트가 멈춤</li>
<li>깊은 네트워크의 성능 저하</li>
</ul>
<p>주요 대응:</p>
<ul>
<li>ReLU 계열 활성화 함수</li>
<li>Xavier 또는 He 초기화</li>
<li>Batch Normalization</li>
<li>Residual Connection</li>
<li>LSTM 또는 GRU</li>
</ul>
<h3 id="102-gradient-exploding">10.2 Gradient Exploding</h3>
<p>큰 값이 반복해서 곱해지면 기울기가 폭발적으로 커집니다.</p>
<p>결과:</p>
<ul>
<li>가중치가 지나치게 크게 변경</li>
<li>손실 발산</li>
<li>NaN 발생</li>
</ul>
<p>주요 대응:</p>
<ul>
<li>Gradient Clipping</li>
<li>적절한 가중치 초기화</li>
<li>Learning Rate 조정</li>
<li>Batch Normalization</li>
</ul>
<h2 id="11-gradient-clipping과-weight-decay">11. Gradient Clipping과 Weight Decay</h2>
<h3 id="gradient-clipping">Gradient Clipping</h3>
<p>기울기가 임계값을 넘으면 크기를 제한합니다. 방향은 유지하고 norm만 제한하는 방식을 자주 사용합니다. 기울기 폭발을 막는 안전장치입니다.</p>
<h3 id="weight-decay">Weight Decay</h3>
<p>큰 가중치에 패널티를 주어 모델이 과도하게 복잡해지는 것을 막습니다.</p>
<p>$$
L_{total}=L_{data}+\lambda\sum_jw_j^2
$$</p>
<p>Weight Decay는 기울기 자체를 시간에 따라 줄이는 의미와 다르며, 과적합 완화와 일반화 성능 향상이 주목적입니다.</p>
<h2 id="12-dropout">12. Dropout</h2>
<p>Dropout은 학습할 때 일부 뉴런을 무작위로 비활성화합니다.</p>
<pre><code class="language-text">Training: 매 Batch마다 일부 뉴런을 무작위로 끔
Inference/Test: 모든 뉴런을 사용하고 출력 크기를 보정</code></pre>
<p>효과:</p>
<ul>
<li>특정 뉴런 조합에 과도하게 의존하는 현상 완화</li>
<li>여러 작은 네트워크를 함께 학습하는 것과 비슷한 효과</li>
<li>과적합 완화</li>
</ul>
<blockquote>
<p><strong>중요:</strong> Dropout은 뉴런을 무작위로 비활성화하는 규제 기법입니다. Early Stopping은 Validation 손실이 더 이상 좋아지지 않을 때 학습 자체를 중단하는 기법입니다. 둘은 서로 다릅니다.</p>
</blockquote>
<h2 id="part-2-핵심-정리">Part 2 핵심 정리</h2>
<ul>
<li>순전파는 예측하고, 역전파는 기울기를 계산하며, Optimizer는 파라미터를 업데이트합니다.</li>
<li>Learning Rate가 너무 작으면 느리고 너무 크면 발산할 수 있습니다.</li>
<li>Adam은 방향과 변동 크기를 활용하지만 전역 최솟값을 보장하지 않습니다.</li>
<li>기울기 소실은 ReLU·초기화·정규화 등으로, 폭발은 Clipping 등으로 완화할 수 있습니다.</li>
<li>Dropout과 Early Stopping은 작동 방식이 다른 규제 방법입니다.</li>
</ul>

<h1 id="part-3-데이터-구조">Part 3. 데이터 구조</h1>
<h2 id="1-시험-공부로-보는-학습-단위">1. 시험 공부로 보는 학습 단위</h2>
<ul>
<li><strong>데이터셋</strong>: 전체 문제집</li>
<li><strong>Batch</strong>: 한 번에 풀 문제 묶음</li>
<li><strong>Batch Size</strong>: 한 묶음의 문제 수</li>
<li><strong>Iteration 또는 Step</strong>: 한 Batch를 처리하고 한 번 업데이트</li>
<li><strong>Epoch</strong>: 전체 문제집을 한 번 모두 학습</li>
</ul>
<h2 id="2-batch-size">2. Batch Size</h2>
<p>데이터가 100개라고 가정해 봅시다.</p>
<h3 id="batch-size--100">Batch Size = 100</h3>
<ul>
<li>100개를 모두 본 뒤 한 번 업데이트</li>
<li>기울기가 비교적 안정적</li>
<li>메모리 사용량이 큼</li>
<li>Epoch당 업데이트 1회</li>
</ul>
<h3 id="batch-size--10">Batch Size = 10</h3>
<ul>
<li>10개씩 보고 업데이트</li>
<li>Epoch당 업데이트 10회</li>
<li>메모리 사용량이 적음</li>
<li>기울기 노이즈가 더 큼</li>
</ul>
<p>작은 Batch가 무조건 더 좋은 것은 아닙니다. 너무 작으면 노이즈가 커지고 하드웨어 병렬성을 충분히 활용하지 못할 수 있습니다.</p>
<h2 id="3-epoch와-step">3. Epoch와 Step</h2>
<p>데이터가 20개이고 Batch Size가 5라면:</p>
<p>$$
Steps\ per\ Epoch=\left\lceil\frac{20}{5}\right\rceil=4
$$</p>
<ul>
<li>1 Epoch: 4번 업데이트</li>
<li>3 Epoch: 총 12번 업데이트</li>
</ul>
<p>Epoch가 지나치게 많으면 Train 데이터에 과적합할 수 있으므로 Train 손실과 Validation 손실을 함께 봐야 합니다.</p>
<h2 id="4-mini-batch">4. Mini-batch</h2>
<p>전체 데이터보다 작은 Batch로 학습하는 방식입니다.</p>
<ul>
<li>GPU 메모리 안에서 대규모 데이터 학습</li>
<li>전체 Batch보다 자주 업데이트</li>
<li>샘플 하나씩 처리하는 것보다 병렬화가 쉬움</li>
<li>적당한 기울기 노이즈가 일반화에 도움을 줄 수 있음</li>
</ul>
<p>각 Epoch 시작 시 데이터를 섞어 Batch 구성이 달라지게 하는 것이 일반적입니다.</p>
<h2 id="5-data-augmentation">5. Data Augmentation</h2>
<p>정답을 바꾸지 않는 범위에서 회전, 좌우 반전, 자르기, 밝기 변화 등을 적용해 데이터를 다양화합니다.</p>
<pre><code class="language-text">고양이 이미지를 조금 회전
→ 여전히 고양이
→ 새로운 학습 예시처럼 활용</code></pre>
<p>단, 숫자 6을 뒤집어 9가 되는 것처럼 의미가 바뀌는 변환은 사용하면 안 됩니다.</p>
<h2 id="6-pytorch-mini-batch-예시">6. PyTorch Mini-batch 예시</h2>
<pre><code class="language-python">import torch
from torch.utils.data import DataLoader, TensorDataset

X = torch.arange(1, 41).reshape(-1, 2).float()

dataset = TensorDataset(X, y)
loader = DataLoader(dataset, batch_size=5, shuffle=True)

num_epochs = 3

for epoch in range(num_epochs):
    for batch_idx, (features, targets) in enumerate(loader):
        # 실제 학습의 대표 순서
        # optimizer.zero_grad()
        # predictions = model(features)
        # loss = loss_fn(predictions, targets)
        # loss.backward()
        # optimizer.step()
        print(epoch, batch_idx, features.shape, targets.shape)</code></pre>
<ul>
<li>전체 X Shape: (20, 2)</li>
<li>전체 y Shape: (20, 1)</li>
<li>한 Batch의 X Shape: (5, 2)</li>
<li>한 Batch의 y Shape: (5, 1)</li>
<li>1 Epoch의 Mini-batch 수: 4개</li>
</ul>
<h2 id="7-batch-normalization">7. Batch Normalization</h2>
<p>Batch Normalization은 학습 시 Mini-batch 통계로 중간 활성값을 정규화하고 학습 가능한 Scale과 Shift를 적용합니다.</p>
<p>$$
\hat{x}=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}
$$</p>
<p>$$
y=\gamma\hat{x}+\beta
$$</p>
<ul>
<li>$\mu_B$: Batch 평균</li>
<li>$\sigma_B^2$: Batch 분산</li>
<li>$\epsilon$: 0으로 나누는 것을 막는 작은 값</li>
<li>$\gamma$, $\beta$: 학습되는 Scale과 Shift</li>
</ul>
<p>기대 효과:</p>
<ul>
<li>기울기 흐름 안정화</li>
<li>더 큰 Learning Rate 사용 가능</li>
<li>빠르고 안정적인 수렴</li>
<li>경우에 따라 약한 규제 효과</li>
</ul>
<h3 id="training과-inference">Training과 Inference</h3>
<ul>
<li>Training: 현재 Mini-batch 통계 사용, Running 평균과 분산 갱신</li>
<li>Inference: 학습 중 누적한 Running 평균과 분산 사용</li>
</ul>
<p>평가할 때 Evaluation Mode로 바꾸지 않으면 예측이 불안정할 수 있습니다.</p>

<h2 id="9-차원별-tensor">9. 차원별 Tensor</h2>
<h3 id="0d-tensor-scalar">0D Tensor: Scalar</h3>
<pre><code class="language-python">x = 1
# shape: ()</code></pre>
<h3 id="1d-tensor-vector">1D Tensor: Vector</h3>
<pre><code class="language-python">x = [1, 2, 3]
# shape: (3,)</code></pre>
<h3 id="2d-tensor-matrix">2D Tensor: Matrix</h3>
<pre><code class="language-python">x = [
    [1, 2],
    [3, 4],
]
# shape: (2, 2)</code></pre>
<p>표 형태 데이터와 흑백 이미지 한 장을 표현할 수 있습니다.</p>
<h3 id="3d-tensor">3D Tensor</h3>
<p>교재의 HWC 관례에서는 컬러 이미지 한 장을 다음처럼 표현합니다.</p>
<pre><code class="language-text">(Height, Width, Channel)
(640, 640, 3)</code></pre>
<h3 id="4d-tensor">4D Tensor</h3>
<p>이미지 여러 장을 Batch로 묶으면 보통 4D입니다.</p>
<pre><code class="language-text">TensorFlow 계열: (Batch, Height, Width, Channel)
PyTorch 계열:   (Batch, Channel, Height, Width)</code></pre>
<p>동영상 한 편도 (Frame, Height, Width, Channel) 형태의 4D Tensor가 될 수 있습니다.</p>
<h3 id="5d-이상-tensor">5D 이상 Tensor</h3>
<ul>
<li>영상 Batch: (Batch, Frame, Height, Width, Channel)</li>
<li>3D 의료 영상 Batch: (Batch, Channel, Depth, Height, Width)</li>
<li>Transformer: Batch, Token, Head, Feature 같은 여러 축</li>
</ul>
<p>차원의 수보다 각 축의 의미를 아는 것이 중요합니다.</p>
<h2 id="10-tensor-shape-읽기">10. Tensor Shape 읽기</h2>
<pre><code class="language-python">x = [
    [[\&quot;A\&quot;], [\&quot;B\&quot;], [\&quot;C\&quot;]],
    [[\&quot;D\&quot;], [\&quot;E\&quot;], [\&quot;F\&quot;]],
]</code></pre>
<p>바깥쪽부터 읽습니다.</p>
<ol>
<li>가장 바깥 묶음 2개</li>
<li>각 묶음 안에 3개</li>
<li>각 원소가 길이 1의 묶음</li>
</ol>
<p>따라서 Shape은 (2, 3, 1)입니다.</p>
<pre><code class="language-python">[\&quot;A\&quot;, \&quot;B\&quot;, \&quot;C\&quot;, \&quot;D\&quot;]
# shape: (4,)

[[\&quot;A\&quot;, \&quot;B\&quot;, \&quot;C\&quot;],
 [\&quot;D\&quot;, \&quot;E\&quot;, \&quot;F\&quot;]]
# shape: (2, 3)</code></pre>
<h2 id="11-이미지-shape과-채널-순서">11. 이미지 Shape과 채널 순서</h2>
<p>가로와 세로가 640인 이미지라면:</p>
<ul>
<li>한 행의 픽셀: (640,)</li>
<li>흑백 이미지: (640, 640)</li>
<li>채널 축을 명시한 흑백 이미지: (640, 640, 1) 또는 (1, 640, 640)</li>
<li>컬러 이미지 HWC: (640, 640, 3)</li>
<li>컬러 이미지 CHW: (3, 640, 640)</li>
</ul>
<p>HWC와 CHW 중 어느 것이 정답인지는 프레임워크와 문맥에 따라 달라집니다. 숫자뿐 아니라 축 이름을 확인해야 합니다.</p>
<h2 id="12-reshape와-transpose">12. Reshape와 Transpose</h2>
<h3 id="reshape">Reshape</h3>
<p>원소 순서를 유지하면서 묶는 모양을 바꿉니다. 전체 원소 수는 같아야 합니다.</p>
<pre><code class="language-python">[4, 7, 9, 1, 3, 8]

# reshape (2, 3)
[[4, 7, 9],
 [1, 3, 8]]</code></pre>
<h3 id="transpose">Transpose</h3>
<p>축의 순서를 바꿉니다.</p>
<pre><code class="language-python">[[1, 2, 3],
 [4, 5, 6]]

# transpose
[[1, 4],
 [2, 5],
 [3, 6]]</code></pre>
<p>Reshape는 같은 원소를 새 Shape으로 해석하고, Transpose는 축의 순서를 교환합니다.</p>

<h1 id="마무리">마무리</h1>
<p>교재의 핵심은 딥러닝 용어를 따로 외우는 것이 아니라 하나의 학습 순환으로 연결하는 것입니다.</p>
<blockquote>
<p><strong>신경망은 Tensor를 입력받아 순전파로 예측하고, 손실 함수로 틀린 정도를 계산한 뒤, 역전파로 기울기를 구하고, Optimizer가 가중치를 수정하는 과정을 Mini-batch와 Epoch 단위로 반복한다.</strong></p>
</blockquote>
<p>처음에는 다음 여섯 문장만 확실히 기억해도 충분합니다.</p>
<ol>
<li>가중치와 편향은 데이터에서 학습되는 파라미터다.</li>
<li>활성화 함수는 신경망에 비선형성을 추가한다.</li>
<li>순전파는 예측, 역전파는 기울기 계산을 담당한다.</li>
<li>Optimizer는 계산된 기울기로 파라미터를 업데이트한다.</li>
<li>Batch는 한 번에 학습할 묶음, Epoch는 전체 데이터 한 바퀴다.</li>
<li>Tensor Shape을 읽을 때는 각 숫자가 어떤 축인지 반드시 확인한다.</li>
</ol>
